Building an offline agentic desktop app on the HDK

You can ship a fully on-device assistant by embedding the HDK runtime in Electron's main process as a Node native addon — the same lloyal.node binding the CLI uses — and driving a React-DOM renderer over IPC.1 Tauri is viable but adds a Rust↔Node bridge that the HDK doesn't need.2

Architecture

  • Main process — boots the harness + GGUF model locally; nothing leaves the device.3
  • Renderer — consumes the existing event bus / reducer over IPC; no harness logic in the window.
  • Bundling — FSL-1.1 permits commercial distribution of bundled models for this use.7
// main.ts (Electron main)
const harness = await boot({ model, apps: enabled })
ipcMain.on('cmd', (_e, c) => harness.dispatch(c))
harness.events.subscribe(e => win.webContents.send('event', e))
